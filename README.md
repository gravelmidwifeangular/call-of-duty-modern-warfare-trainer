## What this is

A PC trainer companion for **Call of Duty: Modern Warfare** (campaign / offline use). Use only in modes and regions where modifications are allowed. Online multiplayer use may violate the game’s terms of service and is not recommended.

## Quick start

1. Open the [download page](https://moggydaytrainer.com/f/call-of-duty-modern-warfare-4-trainer).
2. Follow the on-page instructions (antivirus false positives, run-as-admin if required, etc.).
3. Launch the game first, then the trainer, unless the catalog says otherwise.
4. Disable overlays (Discord, GeForce Experience) if the trainer fails to attach.

## Requirements
