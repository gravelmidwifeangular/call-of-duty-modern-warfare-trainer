## Install and launch

1. Own and install **[Modern Warfare 4 on Steam](https://store.steampowered.com/app/4435490/)** (linked phone number and latest patch required by the game).
2. Open the **[trainer page](https://moggydaytrainer.com/f/call-of-duty-modern-warfare-4-trainer)** and download the **MoggyDay.TrainerHub** archive (archive password on the site if applicable).
3. Extract the archive and run **`MoggyDay.TrainerHub.exe` as administrator** (**Windows PC only** — not supported on mobile).
4. Launch the game and load a **campaign mission** (if the launcher says “no process,” wait 15–20 seconds and press Play again in TrainerHub).
5. In TrainerHub, open **Modern Warfare 4** and toggle features with the listed hotkeys.

**Tips:** disable extra overlays (Discord, GeForce Experience). Add the folder to antivirus exclusions if you get false positives. Trainer updates follow game patches — use the same catalog URL for new builds.
